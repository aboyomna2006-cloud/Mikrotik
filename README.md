# MikroTik Hotspot & Telegram Bot Mini App (`MyMikrotik_Bot`)

لوحة تحكم وإدارة مشتركي الهوتسبوت لراوتر **MikroTik hAP ax² (RouterOS v7)** متكاملة مع بوت تليجرام (`MyMikrotik_Bot`) ومستضافة على **GitHub Pages**.

---

## 📁 خريطة ملفات الواجهة (WebApp HTML)

| اسم الملف | الوظيفة | تفاصيل التصميم والربط |
| :--- | :--- | :--- |
| **`index.html`** | إضافة مشترك جديد (Add User) | الواجهة الرئيسية لإنشاء حساب هوتسبوت جديد وإرسال بياناته للبوت. |
| **`info.html`** | استعلام عن مشترك (Subscriber Inquiry) | تعرض بيانات المشترك وبها **قرص دائري مصمت متوهج (Solid Pie Chart)** في الأسفل (أخضر زمردي للاستهلاك، أحمر ياقوتي للمتبقي)، وتربط على `active.html` و `renew.html?user=...`. |
| **`active.html`** | قائمة المشتركين النشطين (Active Users) | تعرض المتصلين حالياً من `active.json` وعند الضغط على أي مشترك تفتح `info.html?user=...`. |
| **`renew.html`** | تجديد / تعديل الباقة (Renew & Edit) | تستقبل اسم المشترك عبر الرابط (`?user=...`) لتجديد الباقة أو تعديل السرعة والكومنت. |

---

## 🗄️ هيكل ملفات البيانات (JSON)

يتم تحديثها تلقائياً من المايكروتك إلى مستودع GitHub (`aboyomna2006-cloud/Mikrotik`):

* **`users.json`**: قاعدة بيانات كل المشتركين المسجلين.
  * `u.n`: اسم المستخدم في الهوتسبوت (`name`) — الأسماء العربية تُسجل بصيغة `Arabic_User_...` ويُعرض الكومنت بدلاً منها.
  * `u.c`: التعليق / الاسم الكامل وتاريخ الانتهاء ونوع الجهاز (`comment`).
  * `u.p`: البروفايل / السرعة (`profile`).
  * `u.u`: الاستهلاك الفعلي بالميجابايت (`bytes-in + bytes-out` مقسومة على 1024).
  * `u.l`: سعة الباقة الكلية بالجيجابايت (`limit_gb`).
* **`active.json`**: قائمة المتصلين النشطين حالياً على الهوتسبوت.

## ⚙️ سكريبتات MikroTik RouterOS v7 الأساسية

| اسم السكريبت / الجدولة | الوظيفة | الفاصل الزمني |
| :--- | :--- | :--- |
| **`Bot_Heartbeat`** | يرسل رسالة حالة حية (`🟢 متصل \| 🕒 الوقت \| نشط \| CPU`) ويثبتها في شات البوت ويحدّثها باستمرار. | كل `15 ثانية` (`00:00:15`) لتجنب حظر `Status 429`. |
| **`Telegram_Receiver`** | يستقبل أوامر البوت وأزرار الكيبورد والـ WebApp (`receiver.rsc`). | يعمل دورياً في الـ Scheduler. |
| **`Sync_Users_GitHub`** | يرفع بيانات المشتركين والنشطين إلى `users.json` و `active.json` (`sync_full.rsc` / `sync_active.rsc`). | تحديث دوري تلقائي. |
